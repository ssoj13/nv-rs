# Audit: `crates/cuda-core-ext` + `crates/nv-wgpu` (read-only, 2026-11-23)

Repo: `C:\projects\projects.rust.cg\cglibs\nv-rs` @ `38ec140`. External references checked:
`cuda-core` @ `348895e` (cargo git checkout), `wgpu-hal` / `wgpu-core` 30.0.2 (cargo registry, the
versions in `Cargo.lock`), CUDA 13.3 `cuda.h` doc comments.

Severity: P0 = UB / memory unsafety / crash / wrong results; P1 = leak, swallowed error, silent
fallback, significant perf; P2 = dedup/SSOT, dead code, doc drift.
Verdict: CONFIRMED = failing path traced in code (and, where noted, against the driver/wgpu source);
PLAUSIBLE = needs runtime/hardware to observe.
