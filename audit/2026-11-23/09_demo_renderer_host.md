## 4) Static/invariant verification performed

- **LaunchParams ABI**: compared every field of `LaunchParams` (renderer.rs:72-143) with `Params` (raytracer.cu:4-76). Order, types and count match; size 640 and offsets 592-632 are asserted on both sides; align 8. Grepped `params.<field>` for all 66 fields: `fractal_xform` and `sat_pos` are never read; `sky_params[1]` and `glass_params[3]` are never read (R19). No shader-read field is left unwritten by the render launch; probe/SDG launches zero the unused fields via `LaunchParams::zeroed()`.
- **SBT layout**: hit records 0-11 (renderer.rs:1352-1365) are `[primary, shadow]` pairs. Instance offsets are floor/mesh-glass/neon 0, fractal 2, sphere 4, OMM 6, CSG RPN 8 (`CSG_SBT_OFFSET`), CSG prim 10 (`CSG_SBT_PRIM_OFFSET`). All raygens trace with `sbtOffset 0, stride 2, miss 0`. Consistent. GAS inputs use one SBT record each (`sbt_offsets: None`).
- **Trace depth**: `LinkOptions::default().max_trace_depth = 1`. Every `optixTrace` is in raygen-called helpers (`trace_primary`/`trace_shadow`, probe/SDG raygens), none in CH/IS. OK.
- **GAS lifetime**: `Instance.child = Child::Accel(Arc<Accel>)`. `InstanceBuffer.children` and the IAS `refs` keep GASes alive, so `compound_gases.clear()` / glass-mesh replacement cannot free GAS memory still referenced by the live IAS. GPU-scattered handles are kept alive by `csg_host.compound_gases` for the scene's lifetime.
- **Flag constants**: `UNBOUNDED=1<<0`, `SINGLE_PRIM=1<<1`, `PURE_UNION=1<<3` (abi.rs); `VISIBLE=1`, `DYNAMIC=2`, `CAST_SHADOW=4` (assembly.rs); shader null guards in `__intersection__csg*` (raytracer.cu:3060-3162). `__intersection__csg_prim` has **no** prim-index bound check (relevant to H1).
- **Update vs rebuild**: `instances_into` UPDATE requires the same `Item::Instances(n)` and ALLOW_UPDATE flags; `ias_build_opts()` has `allow_update:true, compact:false`. The `TrafficOnly` guard `classic + dyn <= d_optix_instances.len()` plus `update_prefix`'s range check prevent count changes on the update path.
- **Stream ordering**: one `stream.synchronize()` ends every frame/subframe (5112, 4794), so pinned staging reuse (`upload_prefix_pinned`, `InstanceBuffer` staging) and grow-buffer frees cannot race prior frames. `rebuild_scene` syncs before dropping GPU state (2214). `PinnedStagingBuffer::ensure_capacity` syncs before freeing.
