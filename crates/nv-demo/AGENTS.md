# `nv-demo` Agent Guide

## What & Why
`crates/nv-demo/` is the flagship interactive RTX showcase binary (`nv-demo`) of `nv-rs` (`130` unit tests + 5 ignored GPU tests as of `a807624`; camera navigation is the external `camera-rs` crate and its tests run there). It exercises OptiX 9 hardware ray tracing (RT Cores), OptiX AI Denoiser & NGX DLSS SR/RR (Tensor Cores), cuFFT 2D diffraction bloom + CUDA tonemapping + zero-churn IAS/traffic/crowd streaming (CUDA Compute SMs), nvJPEG/nvENC export, atomic SDG JSON ground-truth export, and NVML/CUPTI telemetry inside a decoupled **60 Hz paced** `egui` / `egui-dock` / `wgpu` studio UI. [plan1.md](../../plan1.md) (acceleration roadmap) is closed; the open findings and their execution status are in [plan2.md](../../plan2.md) (Wave 3) and [TODO.md](../../TODO.md).

## Callers & Dependencies
- **Callers**: standalone desktop binary (`cargo run -p nv-demo --release`).
- **Workspace crates**: `optix`, `nv-wgpu`, `nv-loader`, `nvrtc`, `nvml`, `cufft`, `nvjpeg`, `nvenc`, `cupti`, `ngx`, `cuda-core-ext`.
- **External CG crates**: `cuda-core`, `cuda-bindings`, `appbus`, `camera` (`camera-rs`, features `egui` + `serde`; flight feel opted in via `CameraDriver::set_nav_extras` in `main.rs`), `csg-core`, `csg-actors`, `csg-scene` (`wgpu`), `csg-device`, `csg-scenes` (`csg-rs` `24b22f5`, 23 crates, 84-slot palette, 15-class `GasLedger` `246/256`), `egui`/`egui-wgpu`/`egui-winit`/`egui_dock`/`egui-phosphor`, `wgpu`, `glam`, `bytemuck`, `serde`, `serde_json`.

## How It Works
```text
winit + 60 Hz paced egui UI (main.rs: PresentMode::Fifo + WaitUntil 16.667 ms, ui.rs)
  |-- appbus::AppBus (StateSlot<RenderStateSnapshot>, UiCommand, RenderControl, RenderEvent)
  v
Async OptiX Render Worker (renderer.rs, rig.stream, live optix::LogFn)
  1. GpuPassProfiler::begin_frame (3-slot CUevent ring, non-stalling cuEventQuery)
  2. CsgGpuHost::step_dynamic (TrafficStateSoA + SceneBuilt::crowd, Freeze Pose zero-motion snap)
  3. CsgGpuHost::sync -> TrafficOnly (dual pinned 2 MiB DMA, growing to 16 MiB + uncompacted Accel::instances_into UPDATE)
                       | FullRepack (persistent GrowDeviceBuffer + InstanceBuffer + in-place IAS BUILD)
  4. Uninterrupted GPU stream burst (ONE end-of-frame fence):
     [IAS/Traffic/Crowd] -> [OptiX RT (SBT records 0..11, 648 B Params)] -> [OptiX Denoiser] -> [cuFFT Bloom] -> [Tonemap / HDR / DLSS-RR Pack]
  5. Single rig.stream.synchronize() -> GpuPassProfiler::poll_completed() -> FrameReady -> wgpu/DLSS/egui
```
- `src/csg_scene_host.rs`: 100% scene-agnostic `csg-scenes` host owning `Option<SceneBuilt>` (`Gundo`, `GundoOSM`, `Marina del Rey`, `SF House of AI`, **110-variant** `Inspector` incl. variant `109` 4-Archetype Crowd Showcase: Urban Human, `RoadSignStickman`, `QuadrupedDog`, 5-finger `SdgMannequin`), per-compound GAS cache, split CSG hit groups at `CSG_SBT_OFFSET = 8` (`hit_csg`, +1 shadow) / `CSG_SBT_PRIM_OFFSET = 10` (`hit_csg_prim`, +1 shadow, 11-GAS actor bank) routing, persistent `GrowDeviceBuffer<T>` pools (incl. `prev_xforms_buf` for `Motion` AOV), dual `2 MiB` (grow-on-demand to `16 MiB`) pinned `cuMemAllocHost_v2` staging buffers (`pinned_staging` + `pinned_prev_staging`), and atomic `export_sdg_json` via `csg_actors::extract_sdg_frame` + `CsgRayOccluder`.
- `src/profiler.rs`: lock-free fixed-capacity `[f32; 120]` `RingBuffer`s (`FrameTimings`), non-stalling 3-slot `GpuPassProfiler` (`cuEventQuery` only, never `cuEventSynchronize`) reporting **RT Cores (OptiX)**, **Tensor Cores (Denoiser / DLSS)**, and **CUDA Compute (IAS / cuFFT / Tonemap)** ms, plus NVML/CUPTI/NGX probing.
- `src/ui.rs`: narrow-dock-safe `dock_scroll` + adaptive `prop_row_widths`/`slider_control_widths` + truncated `equal_grid`/`ComboBox` layout, Apple Maps clickable WGS84 HUD pill, live 4-way `Road Mode` (`3D | C1 | Hybrid | F-Rep`), `Freeze Pose` & `Save SDG JSON` controls, `EnginePhase` / `FROZEN` status badges, master `Fractal` enable toggle, Hero Fractal full TRS (`T * R_z * R_y * R_x * S`), and per-engine `Performance` sparklines.

## Optimizations & Invariants
- **Zero Per-Frame VRAM Alloc/Free Churn**: `optix::InstanceBuffer` (`d_optix_instances` + pinned staging, `256 KiB` initially, grown on demand up to `64 MiB`), uncompacted persistent `Accel::instances_into` (`compact: false`, `allow_update: true`, in-place `OPTIX_BUILD_OPERATION_UPDATE` on dynamic-only frames and in-place buffer reuse on full repacks), and persistent `GrowDeviceBuffer<T>` pools across all CSG library, instance, `prev_xforms`, and AABB buffers yield `0 cuMemAlloc`, `0 cuMemFree`, and `0 Vec` allocs in steady state.
- **Single End-of-Frame Fence**: zero mid-frame `stream.synchronize()` or `cuEventSynchronize()` stalls between RT, Denoiser, cuFFT Bloom, and Tonemap; double-buffered `free_bufs` overlaps Frame `N+1` CUDA/OptiX with Frame `N` Vulkan DLSS/UI presentation.
- **Strict 648-Byte C ABI**: `LaunchParams` (`renderer.rs`) and `Params` (`shaders/raytracer.cu`) are locked by compile-time `assert!` and `static_assert(sizeof(Params) == 648)` + `__builtin_offsetof(Params, csg_prev_xforms) == 592` + `sdg_ray_count` at offset `632` + `classic_motion_count` / `classic_motion` at `636` / `640` + crossfade source sky block `env_from_lo` / `env_from_hi` at `192` / `384`, with `0` `double` tokens in `raytracer.cu`, true per-instance object optical flow (`csg_prev_xforms` + exact 3x3 affine inverse `csg_inv_xform_pt`), deterministic 4x RGSS AA zero-jitter AOV passes, and semantic IDs `0..19` (`18 = PEDESTRIAN`, `19 = ANIMAL`).
- **60 Hz UI Pacing & Safe Persistent IAS**: `main.rs` caps UI redraws to `60 Hz` (`PresentMode::Fifo` + `ControlFlow::WaitUntil(16.667 ms)` via `compute_next_ui_tick`); `ias_build_opts()` explicitly sets `compact: false` (`allow_update: true`) locked by `ias_build_opts_enables_update_and_disables_compaction`; `init_optix` installs a live `optix::LogFn` callback (`log_level = 3`, `NV_DEMO_OPTIX_LOG_LEVEL` override) with explicit `%LOCALAPPDATA%\NVIDIA\OptixCache` hint on `7999`.
- **Articulated Crowds & SDG Capture**: `CsgGpuHost` owns `SceneBuilt` directly, steps both `TrafficStateSoA`/legacy traffic (`!traffic.is_empty()`) and `SceneBuilt::crowd`, snaps `prev_xform = Some(inst.xform)` + `reset_crowd_motion_history()` + `traffic_dirty = true` on `Freeze Pose` `false -> true` transition for zero stale optical flow during clean multi-spp accumulation, and atomically exports `csg_actors::extract_sdg_frame` JSON keypoints/BBoxes (`Save SDG JSON` or auto-sidecar on frozen PNG/JPEG capture).
- **Large-Map Flight & Responsive UI**: progressive Shift ramp (`1x` <= 2s, `2^((t-2)/5)` up to `64x`), altitude-aware speed (`1x..=25x`), `RMB + Wheel` speed multiplier (`0.1..=64x`), and interactive fast-preview (`1 spp`, `<= 2` bounces + `150 ms` settle).

## Traps & Future Improvements

- **csg-rs contracts (adopted 2026-11-23, `csg-rs` `24b22f5`)**: the crowd kernel source is `csg_actors::pod::actor_sim_cuh_source()` (generated `#define` block + header; never paste the raw header); `step_and_emit_actors_cuda` takes 19 parameters (`STEP_KERNEL_ARG_COUNT`, trailing `lod2_pawn_compound`); the walkway patrol-handle layout reaches the steering kernel as generated `ACTOR_WALKWAY_*` defines (`walkway_target_defines`); a packed instance is a crowd bone iff `inst_flags::CROWD_BONE` is set (derived by the csg-scene packer from `DynamicKind::CrowdBone`; never classify by `user_id` range); per-actor crowd visibility is `WorldScene::crowd_actor_visible` (the prefix packer calls it; `set_crowd_culling(false)` while the GPU steps the crowd); `raytracer.cu` reports `csg_instance_semantic(flags, hit.sem_id)`.
- **Open (csg-rs side, R00/R00b)**: `cuda_crowd.rs` still carries its own GPU walkway steering and DEM ground sampling, so csg-rs crowd improvements (walkway height, avoidance, crosswalk yielding) do not reach the render, and traffic has no GPU path. Both move into csg-rs-owned CUDA kernels with the CPU step as oracle; then delete the copy here.
- **Trap (`step_dynamic` dirty flag & SoA traffic)**: `CsgGpuHost::step_dynamic` must set `traffic_dirty` (not `ias_dirty`) and check `!traffic.is_empty()` (not `!traffic.actors.is_empty()`, because `csg-citygen` OSM cities store vehicles in `TrafficStateSoA`), otherwise `sync()` either misses OSM traffic or forces a full 50k-instance repack instead of the `TrafficOnly` fast path.
- **Trap (`ias_build_opts().compact` & `Accel::custom`)**: `optix::BuildOptions::default()` sets `compact: true`, which `Accel::instances_into` rejects at runtime and which causes ~246 serial synchronous GPU compaction stalls in `Accel::custom` during scene/road switches. Always keep `compact: false` for dynamic IAS and GAS builds unless compaction is explicitly batched asynchronously.
- **Trap (`ias_state` `!show_classic`)**: never hash `sat_angle` or `fractal_transform` into `ias_state` when `!show_classic`, or `sat_orbit`/`auto_rotate` will force a full 50k-instance CSG IAS rebuild every frame (`renderer.rs:3679-3797`).
- **Trap, fixed in `02c1cd9` (`rr_last_exposure` NaN sentinel)**: `(exposure - f32::NAN).abs() > 1e-5` is always `false`; use `Option<f32>` or `.is_finite()` checks (`main.rs:1770, 3468-3470`).
- **Trap (`SaveJpeg` & `max_accum == 0`)**: `0u32.saturating_sub(1) == 0`; guard `max_accum > 0` before clamping `accum_count` (`renderer.rs:2890`).
- **Trap, fixed in `02c1cd9`; re-check after the `camera-rs` switch because upstream requests `Hidden` (not `Locked`) during RMB hold-to-fly (`CursorGrabController` one-shot command)**: `camera_egui::apply_cursor` emits `ViewportCommand::CursorGrab(Locked)` once on frame 0; suppressing it on `drag_accum_px < 4.0` without re-emitting later drops OS cursor lock for the entire drag and in persistent fly modes (`main.rs:1189-1348`).
- **Trap (`RoadTerrainTile` Tier 3B & `NEG_DET` normals)**: Tier 3B in `csg_eval.cuh:3069-3076` requires the `first_cell && t_box_in >= tmin - 1e-6f` guard to prevent curb shadow acne; `csg_prim_normal_to_compound` (`csg_eval.cuh:600-611`) must not double-negate mirrored primitive normals.
- **Trap (`Drop` CUDA context binding)**: always call `bind_to_thread()` before releasing CUDA allocations in `Drop` (`cuda_crowd.rs:251`, `renderer.rs:804`).
- **Trap (egui narrow dock inflation)**: never place unbounded `add_sized([w, h], Button::new(long_text))` or untruncated `ComboBox`es inside a `ScrollArea` without locking `inner_w` via `dock_scroll` and `.truncate()`, or sibling sections will clip off the right edge.
- **Trap (camera code)**: camera navigation is the external `camera` crate (`camera-rs`); never copy its sources back. nv-demo-only flight feel is opted in once via `CameraDriver::set_nav_extras` (`main.rs`); `altitude_speed_multiplier` is host policy in `ui.rs` and takes absolute `eye.y`, not height above ground (open: `CAM:D08`).
- **Trap (shader edits)**: `raytracer.cu` is compiled at runtime; a syntax error shows only when the app starts, so every shader change needs an app start, not just `cargo test`. Do not change `Params` size or offsets without the matching `LaunchParams` change and both asserts.
- **Trap (SDG conventions, plan2 Wave 3, pending gate)**: `depth.Z` is planar Z only for `Pinhole`; `Fisheye180`, `Equirect360` and `SlitCam` export Euclidean range (planar Z is undefined without an image plane); miss is `1e6`. Motion is backward flow in pixels, +y down, jitter removed, x wrapped at the 360-degree seam, for all four projections. Classic geometry has semantic `GROUND` (floor) or `UNKNOWN`; its object motion comes from the `classic_motion` table (`GPU:D03`): one row-major 3x4 "current world -> previous world" transform per classic IAS instance, indexed by bits `16..24` of the instance id (`build_ias_into` sets them; bits `0..8` stay the slot kind, `8..16` the sphere hue). The motion history (`prev_camera` + classic poses) moves together via `commits_motion_history`: every published interactive frame, never on shutter subframes, and once per completed SDG burst frame. Cryptomatte on road tiles is per-hit until `csg-rs` stops packing UV into `part_id` (`GPU:D04`).
- **Trap (video output, plan2 Wave 3, pending gate)**: `Mp4Muxer` writes to a hidden `.partial` sibling and renames on a successful `finish`; an empty recording is an error and leaves no file; a crash can leave a stale `.partial` (no sweeper yet).
- **Trap (`LaunchParams` uploads)**: every launch uploads `LaunchParams` through `LaunchUpload` (one pinned block + event, stream-ordered `cuMemcpyHtoDAsync`); never go back to `DeviceBuffer::copy_from_host`, which synchronises the stream on every call. Every launch whose IAS can hold the fractal (render, SDG keypoints) must carry `FractalLaunch::from_settings`, or `__intersection__fractal` marches a zero-parameter shape (`GPU:D21`); the probe IAS is CSG-only.
- **Trap (sky crossfade)**: `sky_color` evaluates `sky_mode_from` with `env_from_lo` / `env_from_hi` and `sky_mode` with `env_params` (`EnvSettings::pack_crossfade`); a new sky mode reads its parameters through the `env` pointer argument, never `params.env_params` directly (`RND:R10`).
- **Trap (dock layout)**: the `egui_dock` layout persists as the `dock` section of `nv-demo.json` (`APP:F19`); `persist::dock_state_from_value` accepts it only with every `DockTab` exactly once, otherwise the section is a load problem and the file is protected like any other unreadable section. Adding a `DockTab` variant therefore resets saved layouts once (reported in the status line).
- **Trap (animation sliders)**: `anim_slider_f32` / `anim_vec3` take their range from `demo_anim::anim_range(key)` (one table, also the oscillation clamp); `ui::tests::anim_slider_keys_are_all_animatable` fails on a key missing from `ANIM_PARAMS`.
- **Future Improvements**:
  - Wire zero-copy CUDA traffic/crowd kernel writing `xform[12]` directly into both `csg_instances[0..D]` and `d_optix_instances[0..D].transform` in VRAM (`0 B` PCIe H2D/frame).
  - Replace host `Instant` DLSS timing with Vulkan `VkQueryPool` timestamp queries for sub-microsecond DLSS GPU timing.
