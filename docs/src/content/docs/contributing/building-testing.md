`nv-rs` pins its host toolchain, treats compiler and Clippy warnings as errors, and enforces strict `unsafe` hygiene and dependency licensing across the workspace.

## Pinned Rust Toolchain

The host workspace toolchain is pinned in `rust-toolchain.toml`:

- **Channel**: `1.99.1`
- **Components**: `rustfmt`, `clippy`
- **Profile**: `minimal`
- **Edition & Resolver** (`Cargo.toml`): Rust `2024`, resolver `"3"`, `Apache-2.0` license

Device crates under `device/` form a separate workspace (`exclude = ["spikes", "device"]` in `Cargo.toml`) pinned to `cuda-oxide`'s toolchain.

## Building & Verification Commands

You can run checks through `bootstrap.py` (stdlib-only Python 3) or invoke Cargo directly with `+1.99.1`.

### Via `bootstrap.py`

```bash
python bootstrap.py c        # cargo fmt --all --check + clippy --workspace --all-targets -- -D warnings
python bootstrap.py t        # workspace tests (-d for debug, -p <crate> to scope, --gpu for #[ignore])
python bootstrap.py b        # workspace build (--release by default; -d for debug)
```

### Direct Cargo Commands

```bash
cargo +1.99.1 fmt --all --check
cargo +1.99.1 clippy --workspace --all-targets -- -D warnings
cargo +1.99.1 test --workspace --lib
```

### GPU & Cross-Platform Verification

- **GPU integration tests**: Tests requiring a physical NVIDIA GPU or runtime driver are marked `#[ignore]`. Run them serialized on a GPU-equipped host via `python bootstrap.py t --gpu`, `cargo xtask gpu-test`, or `cargo +1.99.1 test -- --ignored`.
- **WSL2 / Linux verification**: When modifying Linux-targeted crates (`nccl`, `cufile`, `nv-loader`, `nv-bindgen`, `nv-wgpu`, `ngx`), run `fmt`, `clippy --workspace --all-targets -- -D warnings`, and `test --workspace --lib` inside WSL2 or native Linux in addition to Windows.

## Coverage Tracking (`cargo xtask coverage`)

`xtask` manages symbol coverage tracking across all wrapped NVIDIA libraries:

```bash
cargo xtask coverage collect
cargo xtask coverage generate
cargo xtask coverage check
```

`COVERAGE.md` is generated by `cargo xtask coverage generate` from `coverage/` and must not be edited by hand. It reports per-library counts for **bound** (present in the generated inventory), **wrapped** (referenced by a safe wrapper), and **tested-on-gpu** (backed by a passing GPU test record).

## Workspace Lints

`Cargo.toml` configures strict workspace-wide lints:

```toml
[workspace.lints.rust]
unsafe_op_in_unsafe_fn = "deny"
missing_docs = "warn"

[workspace.lints.clippy]
all = { level = "deny", priority = -1 }
undocumented_unsafe_blocks = "deny"
```

Per `CONTRIBUTING.md`:

- Every `unsafe` block requires a `// SAFETY:` comment explaining the upheld invariants.
- Avoid `#[allow(...)]` suppressions; prefer safe wrappers.
- Explicit backend or feature requests must return typed errors rather than silently downgrading.

## Dependency & License Policy (`deny.toml`)

Run `cargo deny check` before opening a pull request. `deny.toml` enforces:

- **Advisories** (`version = 2`): `ignore = []` (no ignored advisories).
- **Licenses** (`version = 2`, `confidence-threshold = 0.8`): allows `Apache-2.0`, `MIT`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Zlib`, and `Unicode-3.0`.
- **Bans**: `multiple-versions = "warn"`, `wildcards = "allow"`, `highlight = "all"`.
- **Sources**: `unknown-registry = "warn"`, `unknown-git = "warn"`, allowing `https://github.com/rust-lang/crates.io-index` and the explicit SSH git dependencies `vcv-rs.git`, `cuda-rust_b.git`, and `gpu-info-rs.git` under `ssh://git@github.com/ssoj13/`.

## Contributing & Security

- **DCO & CLA** (`CONTRIBUTING.md`): Every commit must include a Developer Certificate of Origin sign-off (`git commit -s -m "..."`), appending `Signed-off-by: Name <email>`. External contributors may also be asked to complete the NVIDIA CLA during PR review. Never commit proprietary NVIDIA headers, redistributable binaries, or generated files outside the permitted build/prebuilt workflow.
- **Security Policy** (`SECURITY.md`): Do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests. Report privately to the NVIDIA Product Security Incident Response Team (PSIRT) at [psirt@nvidia.com](mailto:psirt@nvidia.com) or via [NVIDIA Product Security](https://www.nvidia.com/en-us/security/) (or GitHub Private Vulnerability Reporting if enabled). Unsoundness in safe Rust APIs is treated as a security bug.
